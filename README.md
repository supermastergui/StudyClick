# 🧠 StudyClick（点击式学习系统）

> 一个轻量级、支持离线运行的多学科点击式刷题系统

---

## 📖 项目简介

**StudyClick** 是一个基于浏览器的开源刷题系统，专为学生自主练习设计。

无需输入，只需点击选项即可完成答题，简单高效。

本项目具有以下特点：

- ⚡ 打开即用，无需安装
- 🌐 支持完全离线运行
- 🎯 每次随机生成题目，避免重复练习
- 🧩 易扩展，支持多学科内容

---

## ✨ 功能特点

### 🎯 刷题系统
- 每次打开/刷新随机生成试卷
- 每题 4 个选项（1 正确 + 3 干扰项）
- 点击即可作答，无需输入
- 即时判分：
  - ✅ 正确 → 绿色标记
  - ❌ 错误 → 红色标记
- 同一题不可重复作答

---

### 📊 成绩统计
- 自动统计：
  - 总题数
  - 正确题数
  - 正确率（百分比）

---

### 🔁 再来一套
- 无需刷新页面
- 一键生成全新随机试卷

---

### 📚 错题本
- 自动记录答错的题目
- 使用浏览器本地存储（localStorage）
- 关闭页面后仍然保留
- 支持一键清空

## 🚀 使用方法

1. 克隆项目：

```bash
git clone https://github.com/supermastergui/StudyClick.git
````

2. 打开任意 `.html` 文件

3. 使用浏览器直接运行即可（无需网络）

## 🛠 自定义内容

你可以轻松添加自己的题库：

```javascript
const WORDS = [
  ["apple", "苹果"],
  ["book", "书"],
  ["run", "跑"]
];
```

说明：

* 每一项为：[题目, 正确答案]
* 系统会自动生成干扰选项
